# Dataset Instructions

## Online Retail Dataset

1. Go to: https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci
   (or search "Online Retail II UCI" on Kaggle)
2. Download **online_retail_II.xlsx** (or the original Online Retail.xlsx)
3. Open it in Excel and **Save As → CSV UTF-8** named exactly:

```
online_retail.csv
```

4. Place the file in **this directory** (`./data/online_retail.csv`).

The DAG expects these columns:
`InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country`

Expected date format example: `12/1/2010 8:26`
